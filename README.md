# Complaint Portal

A web app where students submit hostel/college complaints and admins track and resolve them.

## Features
- Student registration and login (passwords hashed)
- Submit complaints with a category
- Track complaint status (Pending, In Progress, Resolved)
- Admin panel to view all complaints and update their status

## Tech Stack
PHP, MySQL, HTML, XAMPP

## How to run locally
1. Install XAMPP and start Apache and MySQL.
2. Copy this folder into `C:\xampp\htdocs\`.
3. In phpMyAdmin, create a database named `complaint_portal` and import `database.sql`.
4. Open `http://localhost/complaint_portal/register.php`.
